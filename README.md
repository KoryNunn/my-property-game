# My Property

A small top-down browser game about keeping your house standing while avoiding council fines. No dependencies or build step.

Run `npm start`, then open http://localhost:4173. You can also open `index.html` using a static web server. Set `PORT` to change the server port.

Survive 90 seconds with your house intact and fewer than three fines. Move with WASD or arrow keys, hold Space near a tree to cut it, hold Shift to sneak, and hold E at a stump to replant. Replanting reduces suspicion and delays regrowth. The house blocks council sight. Falling trees damage the house by 20%. Press P to pause. On-screen controls support touch devices; sound is optional.
